صانع الاختبارات - النسخة المعدلة

التعديلات:
- حذف هوية FIKRA WEB والشعار التجاري.
- إضافة زر للتبديل بين الوضع الليلي والنهاري.
- تحسين بناء الأسئلة: محاولة اكتشاف التعريفات أولاً، ثم إنشاء أسئلة سياقية من الجمل، مع إظهار سياق الإجابة من الملزمة.

التشغيل:
1) فك ضغط الملف.
2) افتح index.html في Chrome أو متصفح حديث.
3) اختر PDF أو TXT وحدد عدد الأسئلة.

تنبيه تقني:
هذه النسخة لا تتصل بنموذج ذكاء اصطناعي خارجي. تحسين الأسئلة هنا مبني على تحليل نصي محلي وقواعد؛ للحصول على أسئلة فهم وتحليل دقيقة ومتنوعة فعلياً، يلزم تكامل AI عبر Backend آمن وعدم وضع مفتاح API في JavaScript العام.
